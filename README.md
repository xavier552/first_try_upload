##  🗄️ SQL
This section contains SQL learning exercises and homework assignments covering:

* SELECT queries — Filtering, sorting, and retrieving data
- Joins — INNER, LEFT, RIGHT, FULL OUTER joins
- Aggregations — GROUP BY, HAVING, COUNT, SUM, AVG, MIN, MAX
- Subqueries — Nested queries and correlated subqueries
- DDL & DML — CREATE, INSERT, UPDATE, DELETE, ALTER
- Constraints — PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL
- Functions — String, date, and numeric
